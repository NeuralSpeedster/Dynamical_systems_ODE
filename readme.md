## 📖 О курсе

Репозиторий содержит исходный код и автоматически компилируемую PDF-версию конспекта по курсу качественной теории обыкновенных дифференциальных уравнений и динамических систем.

### Основные темы конспекта:
- 🧭 **Топологическая динамика:** потоки, фазовые портреты, $\omega$- и $\alpha$-предельные множества, аттракторы.
- 📐 **Двумерные системы:** сепаратрисы, отрезки без контакта, отображение Пуанкаре, классификация положений равновесия.
- 🔄 **Теорема Пуанкаре — Бендиксона:** предельные циклы, сепаратрисные контуры и топологические ограничения на плоскости.
- 📈 **Устойчивость и бифуркации:** устойчивость по Ляпунову, локальные бифуркации, линеаризация.
